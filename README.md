# Family Life € — V6

Versione Flutter multipiattaforma pronta per Android e iPhone.

## Funzioni
- Login e registrazione Firebase
- Famiglia condivisa con codice invito
- Entrate e spese su Cloud Firestore
- Dashboard, movimenti e statistiche
- Foto scontrini da fotocamera/galleria
- OCR Google ML Kit

## Android
Il file Firebase è incluso come `android-google-services.json`. Dopo `flutter create .`, va copiato in `android/app/google-services.json`.

## iPhone
Serve registrare anche l'app iOS in Firebase e aggiungere `GoogleService-Info.plist`.

## Nota
Questo archivio è il progetto sorgente, non un APK compilato.
